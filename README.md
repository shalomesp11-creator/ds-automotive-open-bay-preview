# D&S Automotive Repair Solutions — "Open Bay" website preview

**Demo preview of a website design concept for D&S Automotive Repair Solutions, Columbus, Ohio. This is not the final website.**

- `index.html` — the full page (desktop and mobile layouts)
- `mobile.html` — the same page in three phone-sized frames
- `background.html` — the live storefront environment (animated flag, bay door, shop lights)

## Demo notes

- The shop phone number, hours, and street address have **not** been published yet. They show as "Coming soon."
- The *Schedule Service* form is a demo. It is not connected to anything. Nothing is sent or saved.
- The hero photo is a stock image of a pickup truck in a service bay. It is **not** a D&S location or customer.
- The page asks search engines not to index it.
