# D&S Automotive Repair Solutions — OPEN BAY (website preview)

**Demo preview of a website for D&S Automotive Repair Solutions, Columbus, Ohio. This is not the final website.**

Static HTML/CSS/JS. No build step, no server, no framework.

## What is here

- `index.html` — home page (OPEN BAY hero, popular services, searchable Service Menu, request form, location)
- `services/` — service directory, 16 category pages and 138 individual service pages (each a real `index.html`, so direct links and reloads work on static hosting)
- `mobile.html` — the page in three phone-sized frames
- `background.html` — the animated storefront environment

All links are relative, so the site works from a project sub-path such as GitHub Pages.

## Demo notes

- The phone number **(614) 555-0142** is a placeholder and is not a working number. It is not a `tel:` link.
- Opening hours are **not verified**. The page shows an honest "hours pending" state instead of invented times.
- The *Request Service* form is a demonstration. It is not connected to anything: nothing is sent or saved.
- **Get Directions** opens the shop's Google Maps pin: <https://maps.app.goo.gl/gat129U5YUDfvwSGA?g_st=ic>
- The hero photo is a stock image and is not a D&S location or customer.
